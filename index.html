💰 Monetag Ads Setup Guide

Apni website ko Monetag se link karne ke liye yeh 3 aasan steps follow karein:

1️⃣ Domain Verification:

Monetag dashboard par apni website add karein. Wahan se ek <meta name="monetag" content="..."> tag milega. Usko index.html ke <head> mein paste karein.

2️⃣ MultiTag Script:

Monetag ka MultiTag format sabse best hai (yeh In-Page Push, Vignette Banner aur Interstitial auto-manage karta hai). Iska script tag <head> ke andar paste karein.

3️⃣ Specific Banner Zones:

Hamne code mein pehle se 4 jagahon par Monetag slots bana diye hain:

  • #monetag-top-banner (Top Header Banner)
  • #monetag-in-feed-banner (Articles ke darmiyan)
  • #monetag-sidebar-slot (Sidebar 300x250)
  • #monetag-sticky-bar (Sticky Bottom Banner)
